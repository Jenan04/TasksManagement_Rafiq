# 📝 Taskly - Frontend Developer Training Project

## 🛠️ Tech Stack

- **Core:** [Next.js 15](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS 3.3](https://tailwindcss.com/)
- **State & Logic:** React Hooks (UseState, UseEffect)
- **Tooling:** [pnpm](https://pnpm.io/), [ESLint](https://eslint.org/), [Prettier](https://prettier.io/)

## 🏁 Getting Started

1. **Clone the project:**
   ```bash
   git clone [https://github.com/Jenan-AbuHasanein/tm01.git](https://github.com/Jenan-AbuHasanein/tm01.git)
```

2. **Install dependencies:**
```
pnpm install
```
3. **Run the development server:**
```
pnpm dev
```
